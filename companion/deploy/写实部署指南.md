# 真人写实视频通话 · 部署指南

整体结构：

```
Mac（大脑 DeepSeek + 记忆 + 听你说话）
   │  ① 控制：让她说什么（SSH 隧道 → AutoDL 6006 端口）
   ▼
AutoDL 显卡机器（LiveTalking：把声音变成真人口型视频）
   │  ② 推流
   ▼
阿里云轻量服务器（SRS 中转）──③ 视频画面──► Mac 浏览器
```

---

## 第 0 步："她"的写实视频（已经做好了）

`companion/avatar/` 里准备了两个版本，都是 1280×720、25fps、12 秒、可无缝循环：

| 文件 | 样子 | 说明 |
|---|---|---|
| **`her.mp4`**（推荐） | 居家便装、米白毛衣、披发 | 最像真人视频通话 |
| `her_hanfu.mp4` | 居家穿白色交领汉服上衣 | 保留一点原图的古风感 |
| `her_v1_costume.mp4` | 第一版古装剧照风格 | 旧版本，不推荐 |

制作方式（工具都在 `tools/` 里，以后可以重新生成）：
1. **锁定长相重新拍一张"视频通话照"**（`tools/identity_photo/`）：用原图 `avatar/original.webp` 里她的脸作为身份参考，从头生成手机前置摄像头视角的照片。正脸平视，居家环境，自然光，皮肤有真实质感。不是在原图上修补，所以没有 CG 感。
2. **做成待机视频**（`tools/idle_avatar/`）：用 LivePortrait 加上自然眨眼、轻微头动和呼吸，嘴巴全程闭合。
3. **摄像头质感**：通话时浏览器会在画面上叠加细微的、每帧都在变的传感器噪点和暗角，模拟真实手机摄像头。强度用 `.env` 里的 `CAMERA_GRAIN` 调，0 为关闭。
4. **验证**：300 帧每一帧都能检测到人脸，嘴巴全程闭合，正脸，脸宽约占画面的 24%。

**可选，最真实的版本**：`deploy/autodl_i2v_idle.sh` 会在 AutoDL 的 4090 上用通义万相 Wan2.2 把照片生成带真实微动作的视频（头发、衣服、呼吸都会自然地动）。第一次要下载约 34 GB 模型，每个候选约 10 分钟。用法写在脚本开头。这个脚本没有在 GPU 上实测过，遇到问题把报错发给我。

## 第 1 步：阿里云轻量服务器（视频中转，只需做一次）

1. 阿里云控制台 → **轻量应用服务器** → 点你的实例 → **防火墙** → 添加规则：
   - 协议 **TCP**，端口 **1985**
   - 协议 **UDP**，端口 **8000**
2. 同一页面记下**公网 IP**
3. 点 **远程连接**（Workbench 一键登录），在打开的终端里依次执行：
   ```bash
   cat > srs.sh
   ```
   粘贴 `deploy/aliyun_srs.sh` 的**全部内容**，按回车，再按 `Ctrl + D`，然后：
   ```bash
   sudo bash srs.sh 你的公网IP
   ```
4. 看到 `✅ SRS 已启动` 就完成了，它会开机自动运行。把输出里的**拉流地址**记下来

## 第 2 步：AutoDL 租显卡（每次用的时候开机）

1. AutoDL → **算力市场**，选一台 **RTX 4090**（或 3090），计费方式选**按量计费**
2. 镜像选 **社区镜像**，搜索 `livetalking`，选 `lipku/livetalking`
3. 创建好后，在实例列表点 **JupyterLab**：
   - 左侧文件栏进入 `autodl-tmp` 文件夹
   - 把 `companion/avatar/her.mp4` 和 `companion/deploy/autodl_start.sh` **拖进去**上传
   - 点 **Terminal** 打开终端，运行：
   ```bash
   bash /root/autodl-tmp/autodl_start.sh 你的阿里云公网IP
   ```
   第一次会生成形象，要等几分钟；以后再开机运行同一条命令，几十秒就能启动
4. 在实例列表复制 **登录指令**（类似 `ssh -p 12345 root@connect.xxx.seetacloud.com`）和 **密码**

> **用完记得在 AutoDL 上点"关机"**，关机后显卡不计费。数据盘里的形象会保留。

## 第 3 步：Mac 上连起来

1. 编辑 `companion/.env`，改成：
   ```
   COMPANION_NAME=小雪
   PERSONA_FILE=persona.md          # 用汉服版视频的话，可以改成 personas/清冷仙子.md
   AVATAR_MODE=realistic
   AVATAR_TRANSPORT=rtcpush
   LIVETALKING_URL=http://127.0.0.1:6006
   SRS_WHEP_URL=http://你的阿里云公网IP:1985/rtc/v1/whep/?app=live&stream=livestream
   ```
2. 打开一个**终端**窗口，运行（引号里粘贴第 2 步复制的登录指令），提示输入密码时粘贴密码：
   ```bash
   bash ~/下载/1/companion/deploy/mac_tunnel.sh "ssh -p 12345 root@connect.xxx.seetacloud.com"
   ```
   这个窗口**保持开着**
3. 再开一个终端窗口，运行 `start.sh`，浏览器点 **接通视频**

## 最简单的用法（优云智算 + Mac，各一行命令）

**显卡服务器**（优云智算实例开机后 → JupyterLab → File → New → Terminal，粘贴回车；第一次把 `sk-你的Key` 换成阿里云百炼的 API Key，以后可以去掉 `DASHSCOPE_API_KEY=...` 这部分）：
```bash
cd /workspace && for p in "" https://ghfast.top/ https://gh-proxy.com/; do curl -fsSL -m 60 -o compshare_start.sh "${p}https://raw.githubusercontent.com/z64276166-a11y/1/claude/digital-companion-difficulty-fu7ztw/companion/deploy/compshare_start.sh" && break; done && DASHSCOPE_API_KEY=sk-你的Key bash compshare_start.sh
```
它会自动下载最新脚本和她的视频、生成形象、用通义千问语音启动。

**Mac**（打开"终端"，粘贴回车，按提示粘贴 DeepSeek API Key）：
```bash
curl -fsSL https://raw.githubusercontent.com/z64276166-a11y/1/claude/digital-companion-difficulty-fu7ztw/companion/deploy/mac_install.sh | bash
```
装好后桌面会多一个「和小雪视频」，以后双击它就能启动。显卡服务器 IP 变了的话，在上面这行的 `| bash` 前面加 `GPU_IP=新IP ` 再运行一次。

## 另一条路：优云智算（AutoDL 没卡时用这个，更简单）

[优云智算](https://www.compshare.cn) 有官方的 **"LiveTalking一键部署"** 镜像，模型都已预装，机器自带公网 IP。画面直接推给浏览器，**不需要第 1 步的阿里云中转，也不需要 SSH 隧道**。

1. 注册登录优云智算 → 创建实例，镜像搜索 **LiveTalking一键部署**，地域选 **华北二A**（镜像页面要求的），显卡选 **RTX 4090**（没有就选 3090），计费选**按量**
2. 实例创建好后，在控制台 **配置防火墙 → 添加规则**：
   - TCP，端口 **8010**
   - UDP，端口范围 **50000-51000**
3. 记下实例的**公网 IP**（控制台"基础网络（外）"那一栏）
4. 打开实例的 **JupyterLab**，把 `companion/avatar/her.mp4` 和 `companion/deploy/compshare_start.sh` 拖进左侧文件栏，然后打开 Terminal 运行：
   ```bash
   bash compshare_start.sh
   ```
   第一次会生成形象，要等几分钟，之后再运行就直接启动
5. Mac 上的 `.env` 改成：
   ```
   AVATAR_MODE=realistic
   AVATAR_TRANSPORT=webrtc
   LIVETALKING_URL=http://实例公网IP:8010
   ```
   运行 `start.sh`，点"接通视频"即可（不用开隧道窗口）

> 用完记得在控制台**关机**，按量计费关机后显卡不收费。

## 声音

声音由 AutoDL 上的 LiveTalking 合成，默认 `zh-CN-XiaoyiNeural`（活泼）。想换成温柔一点的，启动时这样写：
```bash
VOICE=zh-CN-XiaoxiaoNeural bash /root/autodl-tmp/autodl_start.sh 你的阿里云公网IP
```

## 遇到问题

| 现象 | 原因 / 解决 |
|---|---|
| 画面黑屏，状态显示"画面没接通" | 检查阿里云防火墙的 TCP 1985 / UDP 8000 是否已开，`SRS_WHEP_URL` 里的 IP 是否正确 |
| 有画面，但她不说话 | 检查 Mac 上的隧道窗口是否还连着，AutoDL 终端有没有报错 |
| 嘴型有点糊 | 现在用的是 wav2lip，跑通后可以升级到 MuseTalk（需要额外下载模型，到时候我帮你配） |
| 画面卡顿 | 换一台离你近的 AutoDL 地区的机器；确认 AutoDL 终端里的 fps 在 25 左右 |

整个流程第一次跑可能会遇到报错，把终端里的报错截图发给我就行。
